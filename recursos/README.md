# Recursos

## Documento oficial
El temario oficial completo (`temario-oficial.pdf`, 647 páginas, 47 MB) **no se sube al repo** por tamaño. Está localmente en esta carpeta y se referencia desde los temas con la nota _"📸 Capturas a incluir: p.X-Y"_.

## Cómo abrir el PDF en una página concreta
```bash
open -a "Preview" recursos/temario-oficial.pdf
```

O desde el navegador de PDFs preferido, ir a la página indicada en cada tema.
